# Libeccio — Webflow Cloud

Version convertie depuis Lovable/TanStack vers Astro + React, selon la méthode utilisée pour L'Oiseau Bleu (`essai-7`).

## Déploiement

1. Mettre le contenu de ce dossier à la racine d'un dépôt GitHub.
2. Utiliser la branche `main`.
3. Dans Webflow Cloud, créer/connecter une App standalone.
4. Framework : Astro.
5. Déployer depuis GitHub.

Les images utilisées par le site sont dans `public/images/`.
